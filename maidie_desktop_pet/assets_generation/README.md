# Maidie 毛绒娃娃资源生成说明

这套文件只负责生成新角色美术，不改变 Maidie 的 Agent、聊天、记忆、数据库、状态机、窗口、交互、缩放、碰撞、打包或其他代码。

## 推荐生成顺序

1. 使用 `prompts/character_master.txt` 和用户提供的《桌宠基准图》，先生成一张正面完整身体母版。
2. 使用 `prompts/character_turnaround.txt` 生成六视图参考，检查左右侧位、后脑勺发型、徽章和短裤标签。
3. 固定正面母版和六视图作为后续所有动画的身份参考，不要让每个状态只依赖文字重新生成。
4. 按 `prompts/` 中的状态文件逐个生成横向精灵条，输出到 `output/`，文件名与提示词文件名相同，格式优先透明 PNG。
5. 先检查 `idle`、`running_right` 和 `running_left`，确认发型、服装、徽章、短裤标签、眼睛、比例和方向全部稳定，再生成其余状态。
6. 所有输出完成后，把 `output/` 整个目录交回 Codex，即可确定性去色键、切帧、组装并替换项目中的 WebP。

## 生图设置

- 角色参考/身份强度：尽量高。
- 尺寸：优先直接输出提示词要求的整条尺寸；若软件不能输出超宽图，逐帧生成时也必须保持同一母版、同一画布、同一中心和同一脚底基线。
- 背景：优先透明；不支持透明时使用完全均匀的 `#00FF00`，不要有阴影、渐变、纹理或地面。
- 帧间一致性：开启固定种子、角色参考、图生图、姿势控制或一致性功能。
- 不要让软件自动加文字、帧号、网格、边框、水印或棋盘格。
- 每格只能有一个完整角色；头发和脚不能被裁切；相邻角色不能重叠。

## 左右方向

`running_right` 与 `running_left` 优先分别生成。角色的胸前徽章、领带和短裤布标具有方向性，不能直接把整张右向图水平镜像成左向图。当前程序运行时仍会按原逻辑镜像 row 1 来显示左向移动，本任务不会修改该逻辑；row 2 只为保持现有 8×9 图集兼容性。

## 生成后替换

生成结果交回后将执行：

1. 检查帧数、透明度、裁切、脚底基线和角色身份一致性。
2. 将 9 条主动画组装为 `1536×1872` 的 `assets/spritesheet.webp`。
3. 将 6 条交互动作分别转为 `1152×208` 的无损 RGBA WebP，替换 `assets/actions/*.webp`。
4. 不修改 `animation/atlas.py`、`ui/sprite.py` 或 `assets/actions/actions.json`。
5. 运行精灵加载、方向、动作清单、打包路径与启动测试。

完整机器可读规格见 `specifications.json`，总览见项目根目录的 `IMAGE_ASSET_REQUIREMENTS.md`。
